# Case evidence-quality review checklist

This checklist is advisory and does not alter the canonical schema or imply independent assurance.

For each case, inspect whether the evidence requirements identify observable evidence, its source and temporal relevance; whether falsification conditions describe an observable unsafe result; and whether a reviewer could distinguish DENY from INDETERMINATE in context.

Do not infer case maturity from a green JSON Schema validation or from a DTFC-authored fixture. Record ambiguous or non-testable conditions as review findings rather than silently editing their meaning.

Review reference links for authorship, stable revision and rights before using them as verified provenance. A valid URL is not a verified source.
